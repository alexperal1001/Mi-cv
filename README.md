## 🛠️ ¿Cómo se genera el PDF?

El PDF se produce con un script en Python puro (sin dependencias externas),
lo que facilita editar el contenido y regenerar el documento:

```bash
python3 generate_cv.py
```

Esto crea el archivo `CV_Alex_Peralta.pdf` con formato profesional de una página.
Para actualizar el CV, edita el texto dentro de `generate_cv.py` (función `build_cv`)
y vuelve a ejecutar el comando.
